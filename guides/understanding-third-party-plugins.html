Understanding Third-Party Plugins

What plugins are and how they extend Reelish.

2 min read

Reelish doesn’t come with any streaming sources. Instead, you add providers — small plugins published by independent authors — that find playable sources for the titles you choose.

Providers and repositories

  • A provider is a script that, given a movie or episode, returns stream links for it. Reelish asks your enabled providers for sources each time you press play.
  • A collection (also called a repository) is a set of providers described by a manifest.json file. You install a collection once, then turn its individual providers on or off.

Providers don’t change the catalog. Titles, artwork and details always come from TMDB; providers only answer “where can this be played?”.

How providers run

Provider scripts run on your device in a constrained JavaScript runtime and can make network requests to their sources. Collections and your enabled-provider choices are saved locally.

Only install what you trust

Providers are third-party code and services. Reelish doesn’t supply or host streams, and community listings are not verified or endorsed by Reelish. Install collections only from publishers you trust.

Code updates need your approval

Updates are downloaded and held for your review before anything changes. If a collection adds a provider or changes a provider’s code, that provider is paused and marked Needs attention until you review it in Plugins and tap Allow update. This way, new code never runs without your say-so.

The community library

Reelish Plugins is a built-in library of community plugin collections, from a community-maintained catalog. Filter it by All, Not installed or Installed, choose a language and sort order, and install a plugin straight from its card. Each card shows the plugin’s version and when it was last updated. The catalog is refreshed at most every six hours (or when you pull to refresh), and a copy is bundled with each release for offline use.

Torrent sources

On Android and Windows, compatible providers can return torrent sources for P2P playback. This only works when P2P streaming is turned on in Settings → Playback, and availability depends on each provider.
