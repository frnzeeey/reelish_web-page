How to install

Windows

Reelish is now on Windows.

Enjoy Reelish on your desktop with an experience adapted for larger screens.

  • Mouse and keyboard navigation
  • Resizable window and fullscreen playback
  • Same plugins, subtitles and settings
Download for Windows

Windows 10 or 11, 64-bit. Run Reelish-Setup-x64.exe: it installs Reelish for your account, without administrator rights, and adds it to the Start menu. Reelish then updates itself from inside the app. The installer isn’t code-signed yet, so SmartScreen may ask you to confirm the first time (More info, then Run anyway). If Windows reports a missing MSVCP140.dll, install the Microsoft Visual C++ Redistributable (x64).
